Why every forgery fails

Each file gets its own key
The 32-byte random salt in the header derives a fresh AES-256 key for this blob alone, so nonces can never repeat across files.
Chunks know where they belong
A chunk's nonce encodes its position and whether it is the last one. Reordered, dropped or appended chunks fail authentication.
Blobs know which file they are
Every tag also covers the header, the file's ID and its version number. A blob can't be swapped for another file's, and an old copy can't be replayed.
Names stay private
In the cloud this blob is stored as , an HMAC of its path. The real names live only in the encrypted index.

Recover files without installing anything

Lost the machine, or just need one file? Point this page at a backing folder, or a copy of it from the cloud, and decrypt files here. Nothing is uploaded: the page can't open network connections.
